# uber-etl-datawarehouse-dashboard
An end-to-end DWBI project developed using Apache NiFi and Metabase to process Uber ride data through ETL pipelines, design a star schema data warehouse, and generate interactive dashboards for trip frequency, fare distribution, revenue trends, and passenger analytics.
